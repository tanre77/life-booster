Неделя того, как вы себя чувствуете, и человек, с которым можно поговорить. Участники записывают настроение, хранят заметки, ведут список лекарств и бронируют видеовизит на 30, 60, 90 или 120 минут. Сопровождающие (в приложении: counselors) публикуют профиль, часы и имя пользователя Venmo.

Это поддержка равных. Сопровождающие не являются лицензированными терапевтами, психологами, психиатрами или медицинскими работниками. Визит — это не терапия, не диагноз и не лечение. Life Booster не отвечает за советы и может отключить сопровождающего без уведомления. В кризисе позвоните или отправьте сообщение на 988.

## Что можно делать

| Вкладка | Кто | Что |
|---|---|---|
| Today | Участник | Записать любой день этой недели, увидеть среднее, добавить лекарства |
| Library | Любой вошедший | Практики по темам, сопровождающие для подписки, бронь визита |
| Visits | Оба | Предстоящие и прошедшие встречи, затем видеокомната |
| Studio | Сопровождающий | Биография, специализации, почасовая ставка, часы, имя пользователя Venmo |
| You | Вошедший | Отображаемое имя, светлое или тёмное оформление |

Вход — электронная почта и пароль, или Apple. Заметки и лекарства остаются частными, пока участник не отметит их как доступные для показа и не включит показ для этого визита.

## Оплата

Бронирование открывает ссылку оплаты Venmo на имя пользователя сопровождающего (`venmo.com`, `txn=pay`). Это не подключение продавца и не подтверждение оплаты. Google Pay — второй вариант через Payment Request API браузера. Apple Pay на экране бронирования нет.

Необязательная скидка спонсора — 2% (`AD_DISCOUNT` в [src/lib/life/money.ts](src/lib/life/money.ts)). Ставки от $15 до $400 в час.

## Запуск

```bash
npm run dev
```

Приложение слушает порт 8080. `npm run typecheck` и `npm run build` должны проходить. Изменения схемы кладите в новый файл в [migrations/](migrations/). Не правьте уже выпущенную миграцию, кроме случая, когда нужно остановить повторный посев данных.

Без `DATABASE_URL` сервер использует встроенный Postgres (PGLite) и применяет [migrations/](migrations/) при старте. С `DATABASE_URL` команда `npm run db:migrate` применяет те же файлы к Neon.

```text
src/routes/          pages

src/components/      shell, mood chart, video room
migrations/          schema, applied in filename order
docs/ARCHITECTURE.md how the pieces fit
docs/PROMPTS.md      tasks with the rules that must not regress
```

Тот же материал по-русски: [архитектура](docs/ru/ARCHITECTURE.md) и [промпты](docs/ru/PROMPTS.md).

Ветки `main`, `web`, `ios` и `android` держатся на одном коммите. Пушьте все четыре вместе.

## Правила продукта, которые легко сломать

- Сопровождающий появляется в People только когда `standing` равен `active` и сохранено хотя бы одно окно часов.
- Часы — это день недели `0` (воскресенье) до `6`, с шагом 30 минут, и конец должен быть позже начала.
- Не сейте примерных сопровождающих (`sample-amira`, `sample-jonah`, `sample-leila`, `sample-mateo`).
- Показ — это два переключателя: заметка или лекарство отмечены как доступные для показа, и у визита есть `share_mood`. Если выключен хотя бы один, сопровождающий этого не видит.
- Таймер визита начинается, когда присоединяется другой человек, и отсчитывает забронированную длительность.
- iPhone воспроизводит голос другого человека на отдельном элементе audio. Удалённое видео остаётся без звука, чтобы звук не застревал на скрытой картинке.
