Тиждень того, як ви себе почуваєте, і людина, з якою можна поговорити. Учасники записують настрій, зберігають нотатки, ведуть список ліків і бронюють відеовізит на 30, 60, 90 або 120 хвилин. Супровідники (у застосунку: counselors) публікують профіль, години та ім’я користувача Venmo.

Це підтримка рівних. Супровідники не є ліцензованими терапевтами, психологами, психіатрами чи медичними працівниками. Візит — це не терапія, не діагноз і не лікування. Life Booster не відповідає за поради і може вимкнути супровідника без повідомлення. У кризі зателефонуйте або надішліть повідомлення на 988.

## Що можна робити

| Вкладка | Хто | Що |
|---|---|---|
| Today | Учасник | Записати будь-який день цього тижня, побачити середнє, додати ліки |
| Library | Будь-хто, хто ввійшов | Практики за темами, супровідники для підписки, бронювання візиту |
| Visits | Обидва | Майбутні й минулі зустрічі, потім відеокімната |
| Studio | Супровідник | Біографія, спеціалізації, погодинна ставка, години, ім’я користувача Venmo |
| You | Хто ввійшов | Ім’я для показу, світле чи темне оформлення |

Вхід — електронна пошта й пароль, або Apple. Нотатки й ліки лишаються приватними, доки учасник не позначає їх як доступні для показу і не вмикає показ для цього візиту.

## Оплата

Бронювання відкриває посилання оплати Venmo на ім’я користувача супровідника (`venmo.com`, `txn=pay`). Це не підключення продавця і не підтвердження оплати. Google Pay — другий варіант через Payment Request API браузера. Apple Pay на екрані бронювання немає.

Необов’язкова знижка спонсора — 2% (`AD_DISCOUNT` у [src/lib/life/money.ts](src/lib/life/money.ts)). Ставки від $15 до $400 за годину.

## Запуск

```bash
npm run dev
```

Застосунок слухає порт 8080. `npm run typecheck` і `npm run build` мають проходити. Зміни схеми кладіть у новий файл у [migrations/](migrations/). Не редагуйте вже випущену міграцію, окрім випадку, коли треба зупинити повторний посів даних.

Без `DATABASE_URL` сервер використовує вбудований Postgres (PGLite) і застосовує [migrations/](migrations/) під час запуску. З `DATABASE_URL` команда `npm run db:migrate` застосовує ті самі файли до Neon.

## Розкладка

```text
src/routes/          pages
src/lib/life/        server functions, catalog, money, time
src/components/      shell, mood chart, video room
migrations/          schema, applied in filename order
docs/ARCHITECTURE.md how the pieces fit
docs/PROMPTS.md      tasks with the rules that must not regress
```

Той самий матеріал українською: [архітектура](docs/uk/ARCHITECTURE.md) і [промпти](docs/uk/PROMPTS.md).

Гілки `main`, `web`, `ios` і `android` тримаються на одному коміті. Пуште всі чотири разом.

## Правила продукту, які легко зламати

- Супровідник з’являється в People лише коли `standing` дорівнює `active` і збережено щонайменше одне вікно годин.
- Години — це день тижня `0` (неділя) до `6`, з кроком 30 хвилин, і кінець має бути пізніше за початок.
- Не сійте зразкових супровідників (`sample-amira`, `sample-jonah`, `sample-leila`, `sample-mateo`).
- Показ — це два перемикачі: нотатку або ліки позначено як доступні для показу, і у візиту є `share_mood`. Якщо вимкнено хоч один, супровідник цього не бачить.
- Таймер візиту починається, коли приєднується інша людина, і відлічує заброньовану тривалість.
- iPhone відтворює голос іншої людини на окремому елементі audio. Віддалене відео лишається без звуку, щоб звук не застрягав на прихованій картинці.
